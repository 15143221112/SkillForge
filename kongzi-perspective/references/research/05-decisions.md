# 05 决策记录与重大转折 · 孔子

> 维度映射：现代人物的重大决策/转折点 → 孔子生平关键抉择及言行一致性。

## 一、关键决策（按时间）

### 决策1：早年自学自立（约前522-前510，30岁前后）
- "吾少也贱，故多能鄙事。"（《论语·子罕》）
- "十有五而志于学，三十而立。"（《论语·为政》）
- **决策逻辑**：出身没落贵族（父叔梁纥早死，母颜徵在迁曲阜），不靠门第，自学礼乐，开始授徒讲学——**首开私学**。
- 言行一致：后来主张"有教无类"，正是从自己非官学出身、广收门徒来的。

### 决策2：适周问礼于老子（约前518，34岁）
- 《史记·孔子世家》载孔子适周问礼于老子。老子诫之："去子之骄气与多欲，态色与淫志，是皆无益于子之身。"【原典·史记】
- **决策逻辑**：主动向可能的论敌（道家前身）请教，不门户之见。
- 言行一致："三人行必有我师""我非生而知之者，好古敏以求之者也"。

### 决策3：出仕鲁国（约前501-前497，51-55岁）
- 中都宰（约前501，51岁）→ 一年后四方皆则之 → 司空 → 大司寇 → 定公十四年（前496，56岁）由大司寇摄相事。【史记·孔子世家】
- **夹谷之会**（前500）：齐景公与鲁定公会于夹谷，孔子摄相事，以"有文事者必有武备"备战，凭外交礼节收回郓、讙、龟阴之田。【原典·史记】
- **政绩**：与闻国政三月，"粥羔豚者弗饰贾；男女行者别于涂；涂不拾遗"。【史记】
- **决策逻辑**：把"仁政德治"从教学落到执政——这是他一生唯一完整的执政试验。

### 决策4：诛少正卯（争议事件，前496？）
- 《史记》："于是诛鲁大夫乱政者少正卯。"【原典】
- **争议**：见 04-external-views。此事与《论语》中"为政以德""举直错诸枉"的风格有张力；若属实，是孔子最铁腕的一刻。
- **保留矛盾**：不洗白、不删除。

### 决策5：去鲁周游（前497，55岁开始，历时约14年）
- 背景：齐人归女乐，鲁定公/季桓子受之，三日不朝，孔子行。（《论语·微子》"齐人归女乐，季桓子受之，三日不朝，孔子行。"）【原典】
- **决策逻辑**：国君沉湎女乐不理政，道不合则去——不恋栈权位。
- 路线：卫→陈→曹→宋→郑→陈→蔡→楚边→卫→陈，往返十四载，68岁返鲁。

### 决策6：陈蔡绝粮不退（前489，63岁）
- 吴伐陈，楚救陈，孔子在陈蔡之间，两国大夫发徒役围孔子于野，不得行，绝粮七日，从者病莫能兴。【史记·孔子世家+论语·卫灵公】
- 子路愠见，孔子曰："君子固穷，小人穷斯滥矣。"【原典】
- 子贡使楚，楚昭王兴师迎孔子，然后得免。
- **决策逻辑**：绝境不放弃主张，不投靠任何一方。楚昭王曾拟封书社之地，令尹子西劝阻（怕孔子得地+贤弟子辅佐成势），昭王乃止——**孔子连楚国的任用机会也因被猜忌而落空**。

### 决策7：拒阳货/公山弗扰/佛肸之召（不与僭臣合作）
- 阳货（季氏家臣）专鲁政，召孔子，孔子不见；时其亡也往拜，遇诸涂，口头答应"吾将仕矣"，实际始终未仕于阳货。（《论语·阳货》）
- 公山弗扰以费畔（叛季氏），召，子欲往，子路不悦，孔子卒不行。（《论语·阳货》）
- 佛肸以中牟畔，召，子欲往，子路质疑，孔子解释"磨而不磷、涅而不缁"，但最终未往。（《论语·阳货》）
- **决策逻辑**：口头不硬顶，行动不合作；对叛臣的诱惑有过动摇（"欲往"），但被弟子劝止——**有过犹豫但守住底线**。

### 决策8：晚年删述六经、归鲁教授（前484-前479，68-73岁）
- 季康子以币迎孔子，归鲁（前484，68岁）。鲁尊为"国老"，问政而不用。【史记+驻委内瑞拉大使馆文化资料】
- 不再求仕，删《诗》《书》，订《礼》《乐》，赞《周易》，修《春秋》。
- **决策逻辑**：政治理想在现实中失败，转向"立言"——把道传下去，而不是权位。
- 卒于鲁哀公十六年（前479），年七十三。

## 二、言行一致性检验

| 主张 | 行为证据 | 一致性 |
|---|---|---|
| 不义而富且贵于我如浮云 | 去鲁不恋栈、拒阳货 | 高 |
| 知其不可而为之 | 周游14年、陈蔡绝粮不退 | 高 |
| 有教无类 | 门下出身多样（颜回陋巷、子贡商贾、子路野人） | 高 |
| 为政以德 | 中都宰→大司寇三月政清 | 高 |
| 忠恕 | 对鲁君尽忠但不愚忠（三曰不朝即去） | 中 |
| 天下有道则见，无道则隐 | 周游却14年不真隐 | **张力点** |

## 三、内在张力（决策层面）

1. **入世担当 vs 无道则隐**："天下有道则见，无道则隐"（《泰伯》）vs 实际周游14年、"知其不可而为之"（《宪问》晨门评价）——他嘴上说隐，身体很诚实地在奔走。
2. **仁爱普遍性 vs 礼的等级性**：仁者爱人，但礼区分君臣父子长幼尊卑——爱有差等（"亲亲为大"），不是博爱。
3. **欲仕 vs 不仕僭臣**：多次"欲往"应叛臣之召，被子路拦下——**有过对权力的渴望，底线是不与乱臣贼子合作**。
