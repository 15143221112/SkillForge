## 二、思想史影响时间线（孔子之后）

| 时期 | 事件 |
|---|---|
| 战国（前475-前221） | 孟子（前372-前289）道性善、倡仁政，发挥"内圣"；荀子（约前313-前238）道性恶、重礼治，发挥"外王"。儒家八派分化（《韩非子·显学》） |
| 秦（前213） | 焚书坑儒，儒家受重创 |
| 西汉（前134，汉武帝元光元年） | 董仲舒上"天人三策"，倡"罢黜百家，独尊儒术"；前136设五经博士。儒学成官方意识形态 |
| 东汉 | 谶纬化；郑玄遍注群经 |
| 魏晋 | 玄学兴起，儒道合流 |
| 唐 | 韩愈倡"道统说"，排佛老；开科取士以儒经 |
| 宋（11-12世纪） | 程颢程颐奠基，朱熹集大成（1130-1200），建理学（道学），注《四书章句集注》，"存天理灭人欲"；陆九渊开心心学一派 |
| 明 | 王阳明（1472-1529）心学大成，"致良知""知行合一" |
| 清 | 朴学/考据学（顾炎武、戴震），反宋学空疏；戴震"以理杀人"批理学 |
| 1919 五四 | 新文化运动"打倒孔家店"，陈独秀、鲁迅、吴虞批礼教吃人 |
| 20世纪中后 | 港台新儒家（牟宗三、唐君毅、徐复观）；大陆八十年代文化热批孔与九十年代国学复兴并存 |
| 当代 | 孔子学院全球设立（2004起）；官方"国学热"与学术上"回到真孔子"并存；女性主义、自由主义视角持续批评"唯女子与小人""三纲"等文本 |

## 三、时间线关键观察

1. **政治失败 vs 立言成功**：一生执政不足5年，却影响中国2500年——他自己晚年选择"立言"而非"立位"。
2. **被神圣化与被妖魔化交替**：汉以后官方尊孔（大成至圣文宣王），五四以后打倒，当代再复兴——孔子形象被每个时代重新剪裁。
3. **弟子守墓三年、子贡六年**：弟子关系本身是"有教无类""为师"实践的最后注脚。
