# 06 · 时间线 —— 生平 + 思想史影响

> 维度映射：老子生平时间线 + 老子思想两千年影响时间线。
> 注意：老子生卒年史无定论，以下均为"约/传统说法"。

## 一、生平时间线（春秋末期）

| 时间 | 事件 | 出处/可信度 |
|---|---|---|
| 约前 571 年（周灵王元年） | 生于楚国苦县厉乡曲仁里（今河南鹿邑太清宫镇），姓李名耳，字聃 | 《史记》："楚苦县厉乡曲仁里人也，姓李氏，名耳，字聃"；生年据后人推算。政府文化页 https://www.zhoukou.gov.cn/... |
| 青年–中年 | 任周王室守藏室之史（藏书室史官） | 《史记》 |
| 约前 6 世纪中叶 | 孔子适周问礼于老子（孔子约 30 岁，约前 518 年前后，传统说法） | 《史记》；《庄子》多版本寓言。人民网 http://culture.people.com.cn/n1/2016/0129/c22219-28095002.html |
| 居周久之 | "见周之衰，乃遂去"，西行 | 《史记》 |
| 约前 516 年前后 | 过函谷关（一说散关），关令尹喜强留著书，作上下篇五千余言，而去，莫知其所终 | 《史记》；人民网 http://cpc.people.com.cn/n/2015/0107/c179979-26339429.html |
| 卒年 | 不可考；《史记》存异说："盖老子百有六十余岁，或言二百余岁"；后世传统说法约前 471 年 | 传说层，可信度低 |

> 【重要存疑】司马迁本人并列三说：老聃 / 老莱子 / 周太史儋"或曰儋即老子，或曰非也，世莫知其然否"。本 skill 采用主流共识：老子即老聃（李耳），《道德经》为其临终应关令尹喜之请所作（成书过程或有后学润色，学界有争议，但不影响思想归属）。

## 二、思想史影响时间线

| 时期 | 事件 |
|---|---|
| 战国中期（前 4–3 世纪） | 庄子继承发扬，"其要本归于老子之言"（《史记》）；《庄子》多寓言借孔子问礼发挥。郭店楚简《老子》摘抄本出土（1993），证明战国中期《老子》已流传 |
| 战国末–汉初 | 黄老之学兴起，老子"无为"被改造为君人南面术；汉初文景之治用黄老 |
| 西汉（前 1 世纪） | 司马迁作《史记》为老子作传，与韩非合传 |
| 东汉（2 世纪） | 张陵五斗米道尊老子为教主（太上老君），《老子想尔注》把哲学经典宗教化——老子被道教化挪用 |
| 三国魏（3 世纪） | 王弼作《老子道德经注》，玄学三玄之一（老、庄、易）；玄学清谈盛行 |
| 魏晋南北朝 | 玄学发展《老子》形上思辨，为佛教般若学"格义"提供概念框架 |
| 唐代 | 皇室尊老子为李姓始祖，封"太上玄元皇帝"，《道德经》成为科举考试内容 |
| 宋明 | 理学（程朱）糅合道、佛入儒；老学注疏层出不穷（宋徽宗、王安石、司马光等皆有注） |
| 现代 | 陈鼓应《老子今注今译》等哲学史家去宗教化重读；《道德经》成为全球翻译语种最多的中国经典之一 |

## 三、信息不足/过时说明

- 老子生平无任何现代意义上的"最近动态"（历史人物）。
- 生年卒年不可考，所有具体年份都是后人推算。
- 《道德经》成书年代（一人一时之作 vs 道家学派累积）学界仍有争论（郭店本与今本有差异）。
