# 05 · 决策记录与重大选择

> 维度映射：老子生平决策极少且都来自《史记》（二手追记，距老子约 400 年）。
> 每条标注：决策/背景/逻辑（从其著作反推）/可信度。

## 一、可考的重大决策

### 决策 1：任周守藏室之史（国家图书馆馆长）
- 【史籍】"周守藏室之史也。"（《史记》）
- 背景：春秋末期，洛阳是周王室文献中心。
- 【推断】这个位置使他遍读历代典籍、见惯王朝兴衰——这是他"道论"的经验底色：见过太多王朝从盛到崩，所以信"物极必反"。
- 可信度：中（《史记》单传，无旁证，但无反证）。

### 决策 2：见周之衰，去周隐遁
- 【史籍】"居周久之，见周之衰，乃遂去。"（《史记》）
- 背景：春秋晚期周王室衰微（王子朝之乱后王室典籍流散、诸侯称霸）。
- 【推断】逻辑对应《道德经》："功成身退，天之道"（九章）；"得其时则驾，不得其时则蓬累而行"（答孔子语）；"塞其兑，闭其门，终身不勤"（五十二章）。他不选择像孔子那样"知其不可而为之"，而选择不与衰落的王权绑定。
- 可信度：中。

### 决策 3：出函谷关，应关令尹喜之请著五千言
- 【史籍】"至关，关令尹喜曰：子将隐矣，强为我著书。于是老子乃著书上下篇，言道德之意五千余言而去。"（《史记》）
- 【推断】关键性格证据：他本来不想写，是被"强"请才写。著书不是他的野心，是临别赠言。这解释了为什么《道德经》是格言体而非体系巨著——它本来就是一份临别提要。
- 可信度：中（《史记》，但属传说层）。

### 决策 4：莫知其所终——不留下结局
- 【史籍】"莫知其所终。"（《史记》）
- 【推断】这本身就是他的终极决策：不被后人供奉、不立墓碑、不交代下落。对应"功成事遂，百姓皆谓我自然"（十七章）、"圣人后其身而身先，外其身而身存"（七章）。
- 可信度：不可考，只能说"史无记载"。

### 决策 5：答孔子问礼——不接礼学，直接劝其去骄去欲
- 【史籍】见 02-conversations.md 引原文。
- 【推断】面对当时最负盛名的青年学者（孔子适周问礼），他不顺着对方的问题答（怎么复礼），而是拆掉问题本身："你说的那些人骨头都朽了"。这是典型的老子式决策：不参与对方预设的游戏。
- 可信度：中（《史记》；《庄子》另有多版本，但都是寓言）。

## 二、言行一致性检验

| 他说的 | 他做的 | 一致？ |
|---|---|---|
| "功成身退" | 见周衰即去 | 一致 |
| "自隐无名" | "其学以自隐无名为务"，莫知所终 | 一致 |
| "深藏若虚"（告孔子） | 被尹喜强请才著书 | 一致 |
| "圣人无常心，以百姓心为心" | 无任何为政记录（他不当政） | 不可检验，属理论 |
| "小国寡民"理想 | 自己选择隐遁而去，不去实践任何社会改造 | 一致（他不实践，只描述） |

## 三、他"不做"的事（反模式的行为证据）

- 不收徒、不讲学、不辩论（与孔子"有教无类"、墨子"巨子"制度正相反）。
- 不著书（被强请才写五千言）。
- 不仕诸侯（去周后西游，不归）。
- 不称霸王、不留名（"老子，隐君子也"——司马迁结语）。
