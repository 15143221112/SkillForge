# BOOK_OVERVIEW.md — 整书理解（Adler 四步）

## 1. 这是一本什么书（结构）
《论语》非体系著作，而是孔子及其弟子言行的语录汇编，二十篇约五百章，章短、对话体、随问而发。全书无严密论证链，靠**同一概念在不同语境下被反复追问**（仁、礼、学、君子）形成同心圆结构：
- 内圈：为学（学而）→ 修身（三省、九思）
- 中圈：待人接物（忠恕、孝弟、交友）
- 外圈：为政/君子（正名、义利、仁政）
- 主轴：**学—思—行—省的闭环**，以"仁"为价值总纲，以"礼"为行为节度，以"君子"为人格理想。

## 2. 它在讲什么（主旨）
一句话：**人可以通过"好学—内省—克己—推己及人"的日常修养，成为"君子"，并以此成事、安人、安百姓。**
- 仁（仁者爱人、己欲立而立人）是目的；
- 礼（克己复礼、四勿）是规矩；
- 学（学而时习、学思结合）是入口；
- 君子/小人是对照人格坐标系（喻义 vs 喻利，求诸己 vs 求诸人）。

## 3. 关键术语词典（详见 GLOSSARY.md）
仁、礼、忠恕、君子/小人、学/思、道、德、义、孝弟、正名、中庸、惑/达、闻与达之辨。

## 4. 对它的批判（边界与时代局限，蒸馏时必须声明）
1. 语录体、语境缺失：同一句"问仁"对颜渊、仲弓、樊迟答案不同，**不能抽成普世公式**，必须保留"因材施教"的阅读方式。
2. 时代局限：等级制（君君臣臣、唯女子与小人为难养）、复古倾向（从周、不复梦见周公）、部分伦理与现代平等/法治冲突。蒸馏时**只取可迁移的修身与决策方法，不取具体等级结论**。
3. 语录不等于论证：很多"金句"是结论，不是方法；蒸馏只把**可操作的那一类**做成能力卡。

## 5. 关键任务清单（供阶段1覆盖率核对）
- T1 如何处理"自己不愿被这样对待"的事 → 忠恕
- T2 如何收束过度的欲望/言行 → 克己复礼·四勿
- T3 如何把学了的东西真正变成能力 → 为学闭环（时习/学思/温故）
- T4 如何从一个例子推到同类情形 → 举一反三/闻一知十
- T5 如何对不同人用不同教法/建议 → 因材施教
- T6 如何在"利"与"义"冲突时抉择 → 君子义利之辨
- T7 如何面对自己的错误并改进 → 改过自省（三省/见贤思齐/观过）
- T8 如何避免"过"与"不及"两个极端 → 中庸/过犹不及/和而不同
- T9 如何在名实不符、权责错位时理顺事务 → 正名
- T10 如何交友、规劝而不自取其辱 → 交友边界/成人之美
