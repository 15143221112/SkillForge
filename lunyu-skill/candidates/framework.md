# candidates/framework.md — 框架提取器（决策框架/流程）

| 编号 | 框架 | 原文出处 | 要点 |
|---|---|---|---|
| F1 | 忠恕推己流程 | 里仁15（吾道一以贯之/忠恕）、卫灵公24（其恕乎！己所不欲勿施于人）、雍也30（己欲立而立人，己欲达而达人，能近取譬）、颜渊2（己所不欲勿施于人，在邦无怨在家无怨） | 决策前先做"换位试推"：我不愿被如此对待→不施于人；我欲立→助人立 |
| F2 | 正名链条 | 子路3（名不正则言不顺→事不成→礼乐不兴→刑罚不中→民无所措手足） | 先正名（定义/称谓/权责），再推导行动，否则连环失序 |
| F3 | 为学闭环 | 学而1（学而时习之）、为政15（学而不思则罔，思而不学则殆）、为政11（温故而知新）、卫灵公31（终日思不如学） | 学→习→思→温故→知新，循环不辍 |
| F4 | 启发式教学 | 述而8（不愤不启，不悱不发，举一隅不以三隅反则不复）、学而15（告诸往而知来者）、公冶9（闻一知十/闻一知二） | 先让对方到"愤悱"临界点再点拨；只教能举一反三者 |
| F5 | 因材施教 | 先进22（求也退故进之，由也兼人故退之）、颜渊1/2/3（问仁三答）、雍也21（中人以上可语上，中人以下不可语上） | 同一问题按对象性格/层次给相反方向的建议 |
| F6 | 九思省察清单 | 季氏10（视思明，听思聪，色思温，貌思恭，言思忠，事思敬，疑思问，忿思难，见得思义） | 一个可随身的"行为前自检表" |
| F7 | 崇德辨惑三步 | 颜渊21（先事后得非崇德与？攻其恶无攻人之恶非修慝与？一朝之忿忘其身以及其亲非惑与？） | 崇德=先付出后收获；修慝=攻己过不攻人过；辨惑=别因一时忿忘身及亲 |
